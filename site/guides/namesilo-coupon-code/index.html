Program membership is free; funding is a separate condition

The Discount Program requires activation and checkout with Account Funds. Each fund addition must be at least $50 during participation and for 30 days after cancellation; there is no minimum balance to keep. This is prepaid account credit, not a $50 membership fee. Active-domain counts exclude expired or suspended domains.

The official restriction is explicit: Coupon codes cannot be used while enrolled in the Discount Program. A separately advertised coupon cannot be assumed to stack with these rates.
