Registration is not renewal

Namecheap's .com price page separately showed a one-year renewal row of $18.48 when read October 5, 2026 (exact time not preserved). The monthly coupon page's domain card describes registration and transfer, and its disclaimer says first-year registrations and transfers only. A first-year code cannot be treated as an advertised renewal discount. The .com page also says an annual $0.20 ICANN fee is added to the listed price for some domains; the final cart is the place to confirm its application. This is a comparison of purchase routes, not a savings calculation or a verified future invoice.

How to check a code before paying

  1. Open Namecheap's current monthly coupon page and match the code to your product: domain registration or transfer, Professional Business Email, or SAN SSL.
  2. Read the code's current dates and product limits. For a domain, distinguish registration, transfer, and renewal before entering anything.
  3. Continue to the official cart for your exact item and term. Check whether the code is accepted and whether the payable total changes, including any fees or tax. HostDealRadar did not perform this checkout.
  4. If you are renewing, compare the cart with the official renewal row for your exact extension. A code field or an old user report does not establish that a renewal discount applies.
